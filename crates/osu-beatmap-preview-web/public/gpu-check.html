WebGPU 自检

这个页面不加载 wasm，只用浏览器原生 API 检查 WebGPU 是否可用。检查结果可帮助定位失败阶段。

没有可用适配器时怎么排查？

WebGPU 可以使用受支持的核显，不要求独显；high-performance 只是选择偏好。是否可用取决于浏览器、操作系统、显卡型号和驱动。手机上不同浏览器的支持情况也可能不同，版本号本身不保证可用。

  1. Edge：打开设置 → 系统和性能，启用“使用图形加速（如果可用）”，然后重启浏览器。
  2. 在 Edge 地址栏输入 edge://gpu（Chrome 使用 chrome://gpu），查看 Graphics Feature Status 中的 WebGPU，以及 Problems Detected 和 Driver Information。浏览器限制网页直接打开这些内部地址，请复制到地址栏。
  3. 更新浏览器和显卡驱动。远程桌面、虚拟机、组织策略或浏览器兼容性屏蔽也可能影响可用性，需结合上述诊断信息判断。

存在 navigator.gpu 或成功创建 canvas 上下文，仅表示 API 已暴露；还必须取得适配器并成功创建设备。软件回退并非所有浏览器都提供。
