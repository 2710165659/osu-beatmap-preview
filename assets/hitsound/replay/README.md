# 回放提示音

回放使用以下内嵌样本作为默认回退，谱面包中的同名样本优先：

| 文件 | 用途 |
| --- | --- |
| `combobreak.wav` | 断连提示 |
| `failsound.wav` | 回放失败提示 |

样本原样来自 [ppy osu-resources / Argon Gameplay Samples](https://github.com/ppy/osu-resources/tree/master/osu.Game.Resources/Samples/Gameplay/Argon)，由 Argon Pro 继承。文件没有转码或预先调整音量。
