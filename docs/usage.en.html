osu! Beatmap Preview

osu! beatmap preview tool · Supports Standard / Taiko / Catch / Mania four modes · GIF · PNG · MP4 rendering · GPU accelerated · Mod support
Single executable · No runtime dependencies NVENC / AMF GPU Acceleration Windows / Linux / macOS High Performance

1 Usage

osu-beatmap-preview --bid=<BID> [options]

2 Parameters

--bidRequired
Beatmap ID, the only required argument.
--convert
Conversion mode, options: mania / ctb / taiko, only available for Standard beatmaps.
--mods
Mod combination, joined with +, e.g. hd+hr; speed mods can have values e.g. dt1.25; DA can have parameters e.g. daar5cs7.
--fmt
Output format: gif / png / mp4, defaults by mode if omitted. mp4 outputs H.264 video of the full beatmap, supports GPU acceleration.
--time
GIF time points or MP4 time range. GIF up to four, joined with +; MP4 exactly two t1+t2 for clip start/end (seconds), renders full beatmap ±2s if omitted.
--gap
Taiko PNG only: specify spacing BPM so taiko notes render with beat spacing of that BPM, e.g. --gap=180.
Other Parameters
--no-cache
Skip download cache and output cache, force re-download and re-render.
--version
Print version and build time then exit, no rendering.

3 Examples

Basic
osu-beatmap-preview --bid=123456
Convert
osu-beatmap-preview --bid=123456 --convert=mania
Force GIF
osu-beatmap-preview --bid=123456 --convert=mania --fmt=gif
Mod Combo
osu-beatmap-preview --bid=123456 --mods=hd+hr
Time Points
osu-beatmap-preview --bid=123456 --time=10+25+60
Complex
osu-beatmap-preview --bid=123456 --convert=mania --fmt=gif --mods=4k+ds+in+dt1.2 --time=10+30+50
MP4 Video
osu-beatmap-preview --bid=123456 --fmt=mp4
MP4 Clip
osu-beatmap-preview --bid=123456 --fmt=mp4 --time=30+60

5 Mod Rules

DT/HT
Mutually exclusive. DT defaults to 1.5x, range 1.01–2.00; HT defaults to 0.75x, range 0.50–0.99.
EZ/HR
Mutually exclusive.
TC/HD
Mutually exclusive.
1K–10K
Mutually exclusive, only effective with --convert=mania.
IN/HO
Mutually exclusive.
DA/EZ/HR
DA cannot be used with EZ or HR, Standard only.
DA Parameters
Format da<param><value>, e.g. dacs5, daar9.5, can be combined e.g. dacs5ar9.5.

6 MP4 Video Rendering

Use --fmt=mp4 to output H.264 video (15fps · 16:9), supports all four modes, renders full beatmap ±2s by default, or specify a clip with --time=t1+t2.

⚡ GPU Accelerated Encoding

Video encoding auto-detects and uses hardware acceleration, priority:

🟢
NVIDIA NVENC (NVIDIA GPU) — Windows only, dynamically loads nvEncodeAPI64.dll at runtime
🔴
AMD AMF (AMD GPU) — Windows only, dynamically loads amfrt64.dll at runtime
💻
CPU openh264 (Always available) — Fallback when no GPU

Hardware encoders are only available on Windows. Linux / macOS automatically use CPU encoding. No GPU does not affect compilation or runtime — the program falls back automatically. Set the environment variable OSU_PREVIEW_NO_GPU=1 to force CPU encoding.
